# Формат схемы зала (`shared/plan.json`)

Общий контракт между редактором (`editor/`) и приложением бронирования (`booking/`). Редактор экспортирует `{"v":2, zones, tables, decor}`; booking принимает любой объект, где есть массивы `zones` (не пустой), `tables` и `decor`.

Координаты в «единицах схемы»: ширина зала **360**, ось Y вниз. `x, y` — **центр** предмета, `w, h` — размер до поворота, `rot` — угол в градусах (−180…180, по часовой).

## zones — залы
| поле | тип | смысл |
|---|---|---|
| id | string | уникальный id |
| name | string | название («Лаундж», «VIP 1 · малый») |
| h | number | длина зала (150–1600) |

## tables — столы (то, что бронируют)
| поле | тип | смысл |
|---|---|---|
| id | string | уникальный id (у старых столов совпадает с номером) |
| n | string | номер, который видят гости и хостес (должен быть уникальным) |
| zone | string | id зала |
| x, y, w, h | number | центр и размер; у `round` диаметр = `w` |
| shape | `rect` \| `round` | форма |
| seats | number | сколько гостей можно посадить при брони |
| join | string[] | id столов, которые можно придвинуть (связь симметричная) |
| photo | string | ключ фото из `booking/assets/photos` (`blue`, `crane`, `round`, `corner`, `lounge`, `booth1`, `booth2`, `vip1`, `vip2`) |
| desc | string | описание для гостя |
| deposit | number | депозит, ₸ |
| rot | number? | поворот (новое) |
| ch | 0? | `0` — стулья не рисуются автоматически, они лежат в `decor` (новое) |
| sa | `v`? | у круглого стола на 2: места сверху/снизу (старое) |
| lock | bool? | закреплён в редакторе |

## decor — всё остальное
Общие поля: `id, z (id зала), t (тип), x, y, w, h, rot, label`, иногда `col` (цвет), `fs` (размер шрифта у `text`), `shape` (`round` у колонны), `lock`.

| t | что | заметки |
|---|---|---|
| wall, door, window, column, stairs | стены и проходы | у двери рисуется дуга открывания |
| sofa (+ старые sofab, sofag), sofaL, booth, armchair, pouf | мягкая мебель | `col`: blue, bordo, green, beige, grey, black, purple, mustard, white |
| chair, stool | стул, барный стул | спинка стула — сверху в локальных координатах |
| bar, host, dark | барная стойка, стойка хостес, тёмный блок (диджей, колонка, кухня…) | подпись в `label` |
| roomg, roomd, zone, dance, stage, rug | комнаты, зоны, танцпол, сцена, ковёр | рисуются под остальными |
| plant, aqua, tv | растение, аквариум, экран | |
| text | надпись | текст в `label`, размер `fs` |

Порядок в массиве `decor` = порядок рисования (позже — выше).
