# Secret Together Project

Онлайн-бронь столов для заведения в Актобе + редактор схемы зала. Всё работает в браузере телефона.

- **Открыть готовое:** `dist/booking.html` (гости и хостес, PIN хостес — 1234) и `dist/editor.html` (редактор зала). Скачайте файл и откройте в браузере.
- **Весь контекст проекта для Claude:** [`CLAUDE.md`](CLAUDE.md).
- **Формат схемы:** [`docs/plan-format.md`](docs/plan-format.md).
- **Бизнес-план и цены:** [`docs/business/`](docs/business/).

## Кто что делает
| | Папка |
|---|---|
| dqsha | `editor/` — редактор зала |
| друг | `booking/` — вкладки для гостей и хостес |

## Как начать работать (для напарника)
1. Примите приглашение в репозиторий (придёт на почту GitHub).
2. Установите Claude Code и откройте в нём этот репозиторий (в приложении Claude: вкладка Code → выбрать репозиторий; или в терминале `git clone …` и `claude` в папке).
3. Напишите Claude: «Прочитай CLAUDE.md и расскажи, что тут сделано» — он поймёт весь проект.
4. Работайте в своей ветке и присылайте изменения через Pull Request.

## Сборка и тесты
```
pip install pillow playwright && playwright install chromium
./tests/run_all.sh
```
Правки делаются в `booking/template.html` и `editor/template.html`, готовые файлы появляются в `dist/`.
